# Beitragsformat

Diese Datei ist ein **nicht veröffentlichter Platzhalter** für den redaktionellen Workflow.

Ein realer Beitrag soll im Fließtext insbesondere beantworten:

1. Was ist neu?
2. Warum ist es für IncluLearn.AI relevant?
3. Wie belastbar ist die Quellenlage?
4. Welche Konsequenz oder offene Frage ergibt sich daraus?

Externe Tatsachenbehauptungen werden mit nachvollziehbaren Primärquellen belegt. Preprints werden nicht als peer-reviewed dargestellt.
