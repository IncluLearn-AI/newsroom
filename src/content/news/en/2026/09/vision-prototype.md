## A prototype designed to evolve

The current web prototype is deliberately not a throwaway demo. Navigation, domain foundations, accessibility building blocks, internationalisation and reusable UI components are being prepared so that they can feed into the later platform development.

The actual processing services are not yet connected productively. Content and workflows visible in the prototype remain demo data.

## Accessibility first and DE/EN

German is the reference language, while English is technically maintained in the core views. Several iterations improved focus behaviour, reflow, form boundaries, semantic landmarks and localised system terminology.

Help text and demo actions were also revised so that the demonstration does not imply functionality that is not yet present.

## From isolated screens to an example workflow

A synthetic example workflow now connects central views of the prototype. On 22 September, a concrete semantic demo slice was added to illustrate how structured descriptions could later be integrated into the workflow.

## Public demo

The current state can be explored at the linked test address. The demo supports discussion and preparation; it is not presented as an already productive end-to-end system.
